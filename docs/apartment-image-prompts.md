# Apartment image prompts (Gemini)

The site shows **temporary** photos for these 4 apartments. Generate the real ones with the prompts below.

**How to use**
1. Paste one prompt into Gemini and generate. Ask for **16:9 landscape**, the largest size it offers.
2. Save the image with the **file name shown above that prompt**, in the folder named in that apartment's heading. PNG or JPG are both fine.
3. Tell Claude "apartment images ready". Claude will compress them and check they show up on the site.

Generate all 7 images for one apartment in the **same Gemini chat**, so the building and interiors look like the same home. The first 2 apartments (Cosmos Valley, Green View) already have their own images and are not included here.
