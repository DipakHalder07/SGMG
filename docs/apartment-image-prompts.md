# Apartment image prompts (Google Stitch / Gemini)

The site shows **temporary** photos for these 4 apartments. Generate the real ones with the prompts below. Every image is a bright **daytime** scene.

**How to use**
1. Paste each prompt into Google Stitch, one prompt per screen. Each prompt starts with a code such as `D2-01`, which tells Claude where the image goes.
2. When all 28 are done, export or download them all (a zip is fine) and give Claude the file or folder location.
3. Claude matches each image by its code, compresses it, and puts it on the site.

The first 2 apartments (Cosmos Valley, Green View) already have their own images and are not included here.
